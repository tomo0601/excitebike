# EXCITE BIKE FC — XSERVER デプロイ手順

ファミコン風モトクロスレースゲーム（単一HTML・静的サイト）。
スマホはタイトル画面のQRコードを読み取って参加できます。

## デプロイに必要なファイル

`public_html` 配下にアップロードするのは次の2つだけです。

| ファイル | 役割 |
|----------|------|
| `index.html` | ゲーム本体（HTML/CSS/JS すべて内包） |
| `.htaccess`  | HTTPS常時化・gzip・キャッシュ等のApache設定 |

> `.claude/`（launch.json）はローカル開発用です。**アップロード不要**。

## 手順（XSERVER）

1. **ドメイン／SSLの準備**
   - サーバーパネルで対象ドメインを追加。
   - 「SSL設定」で**無料独自SSL**を有効化（反映に数十分かかる場合あり）。

2. **ファイルをアップロード**
   - 「ファイル管理（WebFTP）」または FTP/SFTP ソフトで、
     `（ドメイン名）/public_html/` を開く。
   - `index.html` と `.htaccess` をアップロード。
   - ※ `.htaccess` は隠しファイルです。FTPソフト側で「隠しファイルを表示」を有効に。

3. **動作確認**
   - `https://（あなたのドメイン）/` にアクセス。
   - PCで開き、タイトル画面のQRコードをスマホで読み取る → スマホでゲームが開き、
     画面下のタッチボタンで操作できます。

## 操作

- **X**：アクセル（通常） / **Z**：ターボ（TEMP上昇、オーバーヒート注意）
- **↑/↓**：レーン移動 / **←/→**：空中の姿勢制御
- スマホ：画面下のタッチボタン

## 仕様メモ

- 完全クライアントサイド（サーバー処理不要）。ベストタイムは端末の `localStorage` に保存。
- QRコードは表示中ページのURL（`https://...`）を埋め込みます。公開URLでアクセスすれば
  スマホからそのまま到達できます（`localhost` では他端末から繋がりません）。
- QR画像は外部API（api.qrserver.com）を訪問者ブラウザから取得します（HTTPS・キー不要）。

## 補足：リアルタイム対戦について

「PC画面にスマホを**コントローラー**として参加させる」リアルタイム共有型は、
常時稼働の通信サーバー（Node + WebSocket 等）が必要で、**XSERVERの通常（共有）プランでは不可**です。
その場合は **Xserver VPS** や別途リアルタイム基盤が必要になります。
現状は「QRで各自スマホからプレイ」できる構成です。
